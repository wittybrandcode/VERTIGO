# VERTIGO — بوابة الدخان SMOKE (قبل أي شحن)

> نفّذ بالترتيب، وانسخ السجل كاملاً (زر ⧉ Copy). البوابة خضراء = صفر أسطر حمراء.

1. افتح اللوحة: الحالة `ready` ولا تحذير mismatch.
2. Build (بدون تحديد): `✓ camera created` + طبقة `VRT_Cam`.
3. حرّك سلايدر Zoom: `✓ zoom` والرقم يتغير في AE.
4. اكتب `1x45` في Rot X: يُرسل `405`.
5. حدد طبقة نص ← Track: `✓ tracking: …` + الاسم ظاهر.
6. حرّك الطبقة: الكاميرا تنظر والفوكس يتبع.
7. Rail: `✓ rail built (2500)` + دائرة أفقية + الكاميرا عليها.
8. اسحب Prog: الكاميرا تدور. Floor/Wall/Side: المستوى يتغير.
9. زر ↺ صف + زر ↺ مجموعة: `✓ reset` / `✓ group reset`.
10. اقفل طبقة الكاميرا 🔒 وحرك سلايدراً: يجب `is locked - unlock` (لا خطأ عام).

الأحمر الوحيد المقبول: `no comp` (بلا Composition) و`build rail first` (بلا حلقة).
